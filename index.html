„Verfügbar“ bedeutet, dass die API oder Codec-Abfrage funktioniert. Es garantiert weder flüssiges Streaming noch die Unterstützung des Parsec-Webclients. Codec-Ergebnisse sind Browserangaben, kein vollständiger Decodiertest. WebRTC wird lokal ohne Kamera, Mikrofon, STUN-Server oder Gegenstelle geprüft.
Auf jedem Gerät Hoch- und Querformat, Touch und Ton prüfen und den Bericht separat speichern. Berechtigungen, Netzwerk und iOS-Version können das Verhalten beeinflussen.
Quellcode auf GitHub · Keine Analyse-Dienste oder externen Skripte.
